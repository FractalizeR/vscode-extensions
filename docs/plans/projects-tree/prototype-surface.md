# Перечисление публичной поверхности vsc-project-lobby

Зачем: план утверждает «покрываем все возможности и настройки прототипа». Утверждение о существующем
множестве требует таблицы, иначе ревью вскроет его по одному контрпримеру за раунд.

**Чем получено:** чтение `package.json` ветки `main` репозитория skttl/vsc-project-lobby (WebFetch,
2026-09-03) + README той же ветки.

**Чего этот способ не видит:**
- дефолты и пороги, зашитые в код и не объявленные в `package.json`;
- контекстные ключи (`setContext`), от которых зависят `when` в меню;
- поведение кэша и инвалидации (в `package.json` не выражено);
- строки UI и тексты ошибок;
- незадокументированные команды, зарегистрированные только в коде.
Эти каналы закрываются чтением исходников прототипа на этапе 02 — до фиксации контрактов ядра.

## Настройки

| Настройка прототипа | Тип / дефолт | Решение для ProjectsTree |
|---|---|---|
| `projectLobby.baseFolders` | array, `[]` | `projectsTree.roots` — переносим 1:1 (плюс метка/алиас корня) |
| `projectLobby.maxDepth` | number, 4 | `projectsTree.maxDepth`, дефолт 4 как в прототипе; семантика фиксируется явно: считается от корня, `0` = только корень |
| `projectLobby.ignoreFolders` | array, node_modules/.git/bin/obj/dist/.vs/.vscode | Поглощается правилами (поле `skip`); дефолтное правило воспроизводит этот список |
| `projectLobby.openBehavior` | enum newWindow/currentWindow | Поглощается действиями: дефолтное основное действие `openFolder` с `window` |
| `projectLobby.faviconWebRoots` | array, wwwroot/public/static/assets/src/assets | `projectsTree.favicon.webRoots`, **этап 07** (не в первом релизе) |
| `projectLobby.faviconMaxDepth` | number, 10 | `projectsTree.favicon.maxDepth`, **этап 07**; порог 10 пересчитывается, а не переносится механически |

## Команды

| Команда прототипа | Решение |
|---|---|
| `refresh` / `refreshing` | Переносим (`refreshing` — состояние иконки, воспроизводим тем же приёмом) |
| `addBaseFolder` | Переносим как `addRoot` (используется и в welcome-экране) |
| `removeBaseFolder` | Переносим как `removeRoot` |
| `openInNewWindow` / `openInCurrentWindow` | Переносим как фиксированные пункты меню |
| `hide` / `manageHidden` | Переносим: скрытие пишет правило с условием `pathEquals` (не регуляркой — путь может содержать метасимволы); «Manage Hidden» — список таких правил |

## Возможности из README

| Возможность | Решение |
|---|---|
| Группировка проектов промежуточными папками, зеркалящая ФС | Базовое поведение дерева |
| Остановка обхода на папке с `.git` | Обобщено до поля `stopDescend`; стратегией корня `descend: submodules` расширено до показа сабмодулей по `.gitmodules` — прототип такого не умеет |
| Открытие `.code-workspace`, если он есть в проекте | Переносим: подстановка `${workspaceFile}` + дефолт основного действия |
| Favicon проекта как иконка узла | Переносим, **этап 07** |
| Кэш результатов сканирования между сессиями | Переносим, **этап 07** — вместе с контрактами отмены и идентичности узлов |
